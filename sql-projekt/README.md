📊 Kreditrisikoanalyse mit SQL

Dieses Projekt nutzt SQL zur Analyse von Kreditdaten mit dem Ziel, Risikoklassen präzise zu identifizieren und datenbasierte Kreditentscheidungen zu ermöglichen.

🎯 Ziel der Analyse:

Ermittlung von Risikofaktoren (Einkommen, Kreditsumme, Zinsen, Beschäftigung)
Entwicklung eines Scoring-Modells für Risikoklassen
Berechnung von Ausfallquoten & Validierung mit Lift-Tabelle

📋 Inhalte der Analyse:

Datenbereinigung & Transformation
Aufbau einer Punkte-Logik für Risikoscores
Aggregationen: Durchschnittswerte pro Risikoklasse
Validierung: Lift-Tabelle & Red-Flag-Beispiele

📌 Zentrale Erkenntnisse:

Höheres Risiko bei niedrigerem Einkommen & kurzer Beschäftigungsdauer
Zinsniveau wirkt als Risikofaktor
Scoring-Modell ermöglicht transparente Klassifizierung

✅ Handlungsempfehlungen:

Anpassung der Kreditvergabeprozesse nach Risikoklasse
Einsatz datenbasierter Scoring-Modelle im Pricing
Frühwarnsysteme für auffällige Muster (Red-Flags)

🛠️ Tools & Methoden:

SQL (Datenabfragen, Aggregationen, Scoring-Logik)
Kreditrisiko-Datensatz (32.000 Einträge)

🎓 Dieses Projekt zeigt, wie SQL-basierte Datenanalyse zur Optimierung von Kreditrisikomodellen und Entscheidungsprozessen eingesetzt werden kann.
